# 자금 회전지도 (Capital Flow Map) 설계

작성일: 2026-08-06
상태: 설계 확정 대기

## 1. 문제

대시보드는 69개 지표 카드와 3종 오버레이(섹터 상대강도·수익률곡선·크로스에셋 모멘텀)를 보여주지만,
전부 **"지금 순위"** 스냅샷이다. 사용자가 실제로 알고 싶은 것은 **"어디서 어디로 옮겨가는 중인가"**
라는 방향과 궤적인데, 현재 화면에는 그것이 없다.

### 이 기능이 필요한 결정적 근거

설계 중 사용자가 제시한 시황 서사를 우리 DB 실측과 대조한 결과, 상당수가 어긋났다
(최근 90거래일 ≈ 4개월, 기준일 2026-08-05):

| 서사 | 실측 | |
| --- | --- | --- |
| 빅테크 차익실현 → 가치주 순환매 | XLK 기술 **+43.6%** | 정반대 |
| 헬스케어·에너지 순환매 수혜 | 헬스 +14.1% / 에너지 **−8.1%** | 에너지는 수혜 아님 |
| AI 전력 인프라로 자본 집결 | XLU 유틸리티 **−4.8%** | 부진 |
| 금 $4,000 박스권 | **$4,306, −7.3%** | 박스권 아닌 하락 |
| 비트코인 보합 | **−19.6%** | 급락 |
| 엔캐리 회귀(엔 강세) | 엔/달러 **157.50** (−1.4%) | 여전히 극단적 엔 약세 |
| ↳ 자금이 일본 채권으로 회귀 | 닛케이 **+23.7%** | 주식 급등과 모순 |

반면 금리 수준 주장은 정확했다(연준 실효 3.63% ← 주장 3.5~3.75%, 미10년 4.62% ← 주장 4.6%).

**서사는 자주 틀리고, 시세는 안 틀린다.** 이 기능의 존재 이유가 여기에 있다 —
들은 이야기가 아니라 측정된 이동을 보여주는 것.

## 2. 북극성과 비목표

**북극성**: 한국 거주 개인투자자가 "지금 내 돈을 지킴/성장/가치 중 어디에 둘까"를
자산군 단위로 판단할 수 있게 한다.

**비목표(명시적으로 하지 않는 것)**
- 개별 종목 추천
- 실제 자금유입액(펀드플로우) 측정 — 아래 3절 참조
- 사모/STO 영역 — 아래 3절 참조

## 3. 관측 가능성 감사

사용자가 제시한 "글로벌 거시 자본 지도"의 5개 대륙을 이 앱의 수집 가능 범위와 대조했다.

| 대륙 | 관측 | 판단 |
| --- | --- | --- |
| 1. 공개 금융 | 대부분 가능 | **1단계 범위.** 갭: 가치/성장 상대(IWD/IWF), MMF 잔고, JGB 10년 |
| 2. 사모 금융 (Private Credit/PE/VC) | **불가** | 비공개·분기지연·유료(Preqin/PitchBook). **제외** |
| 3. 실물/인프라 (AI DC·SMR·전력망) | 상장 대리 가능 | URA·GRID/PAVE·EQIX/DLR. **3단계 후보** |
| 4. 디지털/RWA (스테이블코인·온체인 국채) | 새 수집기 필요 | DefiLlama 무료 API. **별도 사이클** |
| 5. 특수/STO (미술품·IP) | **불가** | 공개 시계열 부재. **제외** |

### 대륙 2·5를 제외하는 이유

상장 대리지표(BIZD·PSP·BX)를 넣으면 "사모대출에 자금이 몰렸다"를
"BX 주가가 올랐다"로 바꿔 말하게 된다. 이는 답이 아니라 **오답을 그럴듯하게 만드는 일**이다.
화면에 `관측 불가`로 명시하는 편이 정직하고 실제로 더 유용하다.

### 대륙 4를 RRG에 섞지 않는 이유

스테이블코인 시총·RWA TVL은 **잔고**이고 나머지는 **가격**이다.
한 산점도에 넣는 것은 범주 오류다. 별도 패널이어야 하며, 따라서 별도 사이클이다.
(다만 이 대륙은 이 앱에서 유일하게 '진짜 자금량'을 볼 수 있는 영역이라 가치가 높다.)

### 근본 한계 — UI에 반드시 명시

**가격 상대강도는 실제 자금유입이 아니라 그 대리지표다.**
사모대출에 1조 달러가 들어가도 관련 상장 자산 가격은 안 움직일 수 있다.
진짜 펀드플로우(ETF 설정/환매, EPFR)는 유료라 이 앱에서 쓸 수 없다.
사용자가 "실제 매수금액"으로 오해하지 않도록 화면 각주에 이 문구를 넣는다.

## 4. 1단계 범위 — RRG 자금 회전지도

### 4.1 대상 자산 10종

모든 선정은 DB 실측(일간수익률 상관, VIX 급등일 민감도)으로 검증했다.

선정은 **RRG 좌표를 실제로 계산해서** 확정했다. 일간수익률 상관은 지도 위 분리도를
예측하지 못하므로(아래 참조) 최종 판단 기준은 **만성 겹침 비율**이다:
그날 점구름 지름 대비 거리가 8% 미만인 날의 비율, 30% 초과면 만성 겹침.

| 모양 | 자산 | 키 | 선정 근거 |
| --- | --- | --- | --- |
| 주식 ○ | S&P500 | `sp500` | kospi와 상관 0.179 — 독립 |
| 주식 ○ | 나스닥 | `nasdaq` | 겹침 **24.0%** — 기준 미달. 성장 축 확보 |
| 주식 ○ | 코스피 | `kospi` | **USD 환산.** 4.2절 참조 |
| 채권 □ | 미 장기국채 | `tlt` | **신규 수집.** 현 DB 국채는 전부 *수익률*이라 RRG 불가 |
| 채권 □ | 하이일드채 | `hyg` | 신용 축. tlt(금리·방어)와 양극을 이룸 |

**최종 구성 검증 결과**: 만성 겹침 **0개**, 주의(20~30%) 1개(S&P500~나스닥 24.0%).

**제외 결정과 근거**
- `lqd`(투자등급채): hyg와 겹침 **55.4%** — 통화 기준과 무관하게 만성 겹침.
  둘 다 미 회사채라 본질적으로 같은 자산이다. 채권 축은 `tlt`(순수 금리·방어) +
  `hyg`(신용·위험) 양극으로 커버하는 편이 낫고, 중간값인 lqd의 정보는
  기존 파생지표 `us_hyig`(HY−IG 신용차)가 이미 담고 있다
- `dxy`: usdkrw로 대체
- `silver`·`eth`·`kosdaq`: 각각 gold·btc·kospi와 중복
- `xlre`(부동산): sp500 0.479 / lqd 0.527로 독립적이라 자격은 있으나,
  한국 개인투자자에게 미국 섹터ETF를 자산군으로 격상시키는 것은 과하고
  이미 `sector_rs`에 포함. 모양 6개는 작은 점에서 구분이 무너짐

### 4.1.1 기각된 판단 — 일간상관으로 RRG 겹침을 추정하지 말 것

설계 초기에 `nasdaq`을 "sp500과 일간상관 0.966이므로 점이 겹친다"는 이유로 제외했으나,
실제 좌표를 계산하니 **겹침은 24.0%에 그쳤다**(만성 기준 30% 미달).
현재 두 자산은 **다른 사분면**에 있다 — S&P500 약화(x=101.48, y=99.48) /
나스닥 주도(x=101.43, y=100.49). 제외했다면 "미국 주식 내부에서 성장 쪽 모멘텀이
먼저 돌아섰다"는 신호를 통째로 버릴 뻔했다.

원인은 RS-Ratio의 **롤링 z-정규화**가 작지만 지속적인 격차를 증폭시키기 때문이다.
일간수익률 상관은 이 증폭 후의 분리도를 예측하지 못한다.
**향후 자산 추가·제외 판단은 반드시 RRG 좌표를 계산해서 할 것.**

### 4.2 통화 기준

**달러 기준으로 계산한다. 단 코스피만 USD로 환산한다(`kospi / usdkrw`).**

코스피만 원화 표시(`ccy="KRW"`)라 그대로 두면 통화가 섞인다. 환율 일간 변동폭 중앙값이
코스피의 36% 크기라 63일 누적에서 무시할 수 없다. 코스피를 USD로 맞춰 바스켓 통화를 통일한다.

#### 원화 기준 안을 기각한 이유 (실측)

초안은 "한국 거주 투자자 관점"이라는 이유로 전 자산 원화 환산을 채택했다.
실제로 계산해보니 **저변동 자산이 환율에 삼켜졌다**:

| 자산 | USD 변동성 | 원화환산 변동성 | 원화수익 ~ 환율 상관 |
| --- | --- | --- | --- |
| 하이일드채 `hyg` | **0.402%** | 0.668% | **0.814** |
| 투자등급채 `lqd` | **0.521%** | 0.723% | **0.717** |
| 비트코인 `btc` | 3.293% | 3.317% | 0.134 |
| 구리 `copper` | 1.982% | 1.999% | 0.188 |
| *(환율 자체)* | — | **0.648%** | — |

채권의 자체 변동성(0.4~0.5%)이 환율 변동성(0.648%)보다 작다. 원화로 환산하면
**채권의 원화 수익은 사실상 환율 그 자체**가 되고, 지도 위에서 통화 자산의 복제본이 된다.

만성 겹침 실측 — 원화 기준 → 달러 기준:

```
하이일드 ~ 원/달러    51.9%  ->  15.5%   해소
투자등급 ~ 원/달러    31.5%  ->  13.3%   해소
만성겹침 쌍 개수        3개  ->    1개
```

고변동 자산(btc·copper)은 영향이 미미했다. 즉 **환산 통화의 변동성이 자산 자체의
변동성에 근접할수록 그 자산의 고유 신호가 지워진다.** 채권을 포함한 지도에서
원화 환산은 채택할 수 없다.

> 대시보드 카드의 원화 환산 표시(`is_krw_convertible()`)는 "내 돈으로 얼마인가"를
> 보여주는 별개 목적이므로 그대로 둔다. 여기서 기각한 것은 **상대강도 계산의 기준통화**다.

### 4.3 좌표 계산 (표준 RRG)

```
P'_i(t) = USD 기준 가격 (kospi 만 kospi/usdkrw 로 환산)
N_i(t)  = 100 × P'_i(t) / P'_i(t0)     # t0 = 공통 거래일 교집합의 첫 날 (전 자산 동일)
B(t)    = mean_i( N_i(t) )             # 동일가중 바스켓
RS(t)   = 100 × N_i(t) / B(t)

x = 상대강도   = 100 + (RS − SMA63(RS)) / STD63(RS)      # 중기(3개월) 위치
y = 상대모멘텀 = 100 + (x  − SMA21(x))  / STD21(x)       # 단기(1개월) 방향
```

x가 중기, y가 단기를 맡아 사용자 요구("1M·3M 둘 다 겹쳐서")가 한 그림에 담긴다.
꼬리는 최근 8주(주간 샘플 8점).

**사분면 해석** — 자금은 통상 시계방향으로 순환:
개선(좌상) → 주도(우상) → 약화(우하) → 지체(좌하) → 개선

**날짜 정렬**: `pipeline._compute_derived`와 같은 패턴으로 **공통 거래일 교집합**에서만 계산
(BTC 주말 데이터는 자동 탈락).

**데이터 충분성 검증 완료**: 최종 9종(tlt 제외) 공통 거래일 **744일** (2023-01-17 ~ 2026-08-05).
RRG 요건 130일, 8주 꼬리 40일 모두 충족. `btc` 이력이 2023-01부터라 구간을 자르지만 충분.
`tlt`는 첫 수집 시 5년치 자동 백필(`markets.py:19` `_range_for(1300)` → `"5y"`).

### 4.4 시각 인코딩

| 채널 | 담는 것 | 값 |
| --- | --- | --- |
| **모양 5종** | 자산군 | 주식○(3) 채권□(2) 실물△(3) 코인◇(1) 통화★(1) |
| **색 (연속)** | 위험 성격 | 공격 ← 0 → 방어 발산(diverging) 스케일 |
| **라벨** | 개별 정체성 | 점 옆에 직접 부착 |

**3단계 색상 분류를 폐기한 이유** — 실측에서 경계선 자산의 색이 룩백에 따라 바뀐다:

```
gold   전체 +0.103%  최근2년 -0.080%  최근1년 -0.135%   방어↔중립 깜빡임
hyg    전체 -0.455%  최근2년 -0.490%  최근1년 -0.345%   공격↔중립 깜빡임
```

색이 새로고침마다 바뀌면 신뢰가 무너진다. 임계선을 없애고 연속 스케일로 가면
깜빡임이 원천 차단되고, "금이 예전엔 방어였는데 지금은 옅어졌다"는 변화까지 색에 담긴다.
미수집 상태인 `tlt`의 성격을 미리 추측할 필요도 없어진다(수집 후 자동 반영).

**위험 성격 산출**: VIX 급등일(상위 10%) 평균 수익률, 룩백은 전체 공통구간 고정.
실측값(전체기간): btc −1.880 / sp500 −1.558 / copper −0.737 / kospi −0.669 / hyg −0.455 /
lqd −0.309 / gold +0.103 / usdkrw +0.251 / wti +0.287

> 참고: 손으로 짠 3분류는 실측과 3건 불일치했다(sp500을 중립으로, gold를 방어로,
> kospi를 공격으로 잘못 배정). 하드코딩하지 않고 데이터에서 산출하는 이유다.

색상값은 구현 단계에서 `dataviz` 스킬 기준으로 확정한다.

### 4.5 보조 요소

- **순위 변동표**: 3개월 모멘텀 순위를 현재와 63거래일 전에서 각각 매겨 ▲▼ 표시.
  지도에 없는 자산(nasdaq·silver·eth 등) 포함 전체 표시 — 지도는 좁게, 표는 넓게
- **한 줄 요약**: 사분면 진입/이탈을 **규칙 기반**으로 문장화
  (예: "지난 8주 비트코인·코스피에서 금·달러로 이동 → 방어 국면").
  LLM 미사용 — 브리핑 130~170초가 추가되지 않는다. 기존 `regime` 점수와 방향 일치 여부 병기
- **관측 불가 명시**: 대륙 2(사모)·5(STO)를 화면에 명시적으로 표기

### 4.6 지도 2 — 지역 회전 지도

**RRG는 한 지도 = 한 벤치마크 = 한 계층이어야 한다.** 자산군 지도에 지역 지수를 섞으면
"주식 vs 금"과 "미국 vs 중국"이 같은 축에서 뒤엉킨다. 지도를 둘로 나눈다.

| | 지도 1 — 자산군 회전 | 지도 2 — 지역 회전 |
| --- | --- | --- |
| 질문 | 주식이냐 채권이냐 금이냐 | 주식 안에서 어느 나라냐 |
| 대상 | 10종 (4.1절) | 6종 (아래) |
| 벤치마크 | 크로스에셋 동일가중 | 글로벌 주식 동일가중 |
| 만성겹침 | 0개 (주의 1) | **0개 (주의 0)** |
| 공통 거래일 | 744일 | **915일** |

지역 지도가 오히려 데이터가 길다 — 자산군 지도는 `btc` 이력이 2023-01부터라 잘린다.

| 지역 | 키 | USD 환산 |
| --- | --- | --- |
| 미국 | `sp500` | 불필요 |
| 한국 | `kospi` | `/ usdkrw` |
| 유럽 | `eustoxx` | `× eurusd` |
| 중국본토 | `shanghai` | `/ usdcny` |
| 홍콩 | `hangseng` | 불필요(아래) |
| 일본 | `nikkei` | `/ usdjpy` |

환율 3종(`eurusd`·`usdcny`·`usdjpy`)은 모두 이미 수집 중이다.
**홍콩**은 HKD가 달러 페그(7.75~7.85)라 환산 없이 원값을 쓴다 —
상수 배율은 `N_i(t) = 100 × P/P(t0)` 정규화에서 약분되므로 수학적으로 정당하다.
페그가 깨지면 재검토한다.

`nasdaq`은 지역이 아니라 스타일(성장)이므로 지도 1에만 둔다. 미국 대표는 `sp500`.

#### 지역 지도가 필요한 이유 (실측)

최근 8주 사분면 이동:

```
미국      지체 -> 주도      유럽      지체 -> 주도
홍콩      지체 -> 주도      일본      주도 -> 주도
중국본토   지체 -> 지체      한국      주도 -> 지체   <-- 혼자 반대
```

자금이 한국에서 빠져 미국·유럽·홍콩으로 갔다. **지도 1만 있으면 "코스피 지체"까지만
알 수 있고, 그것이 글로벌 주식 전반의 문제인지 한국만의 문제인지 구분할 수 없다.**
한국 거주 투자자에게 이 구분은 결정을 바꾼다 — 전자면 주식 비중을 줄이는 것이고,
후자면 같은 주식이라도 나라를 옮기는 것이다.

독립성 실측(기본 9종에 하나씩 추가했을 때):

| 후보 | 최대 겹침 | S&P500과 다른 사분면 |
| --- | --- | --- |
| 항셍 | 4.2% | **66.1%** |
| 상하이 | 6.7% | 63.4% |
| 유로스톡스 | 6.9% | 55.1% |
| 닛케이 | 7.1% | 47.7% |

지역 지도 단독 검증에서도 15쌍 전부 겹침 6.1% 이하, 만성·주의 모두 0개.

#### 구현 메모

계산 로직은 두 지도가 완전히 공유한다 — `_rrg(assets, fx_rule)` 하나로 처리하고
자산 목록과 환산 규칙만 주입한다. 색상(위험 성격) 인코딩은 지도 1 전용이며,
지도 2는 전부 주식이라 **모양·색 구분 없이 라벨만** 쓴다.

## 8.5 의도적 미이행 (기록만)

- **4.5절의 "기존 `regime` 점수와 방향 일치 여부 병기"는 구현하지 않았다.** 회전지도의
  방향을 레짐 점수와 대조하려면 "어느 쪽이 위험선호인가"를 한 축으로 뭉개야 하는데,
  자산군 10종의 회전을 단일 축으로 접는 순간 지도의 정보가 사라진다. 어설픈 교차검증은
  없느니만 못하므로 이관하지 않고 미이행으로 남긴다. 필요해지면 별도 사이클에서
  설계부터 다시 한다.
- **픽스쳐가 `silver`·`lqd`·`eth`·`dxy` 를 담지 않는다.** 순위표 18종 중 4종이 검증에서
  '데이터 부족 skip' 분기만 타고 값 분기는 미검증이다. 재동결하면 골든 6블록을 전부
  다시 옮겨야 해서 전사(轉寫) 오류 위험이 코너 커버리지 이득보다 크다고 판단했다.
  주말 봉을 가진 핵심 자산(`btc`)은 이미 픽스쳐에 있고 순위 골든으로 고정돼 있다.
  다음에 픽스쳐를 재동결할 일이 생기면 그때 4종을 함께 넣는다.

  결과 `tlt` 최대 겹침은 **하이일드채와 24.6%** 로 만성 기준(30%) 미달. 최종 10종 구성의
  만성 겹침은 **0개**, 주의(20~30%)는 2쌍이다:

  | 쌍 | 겹침 |
  | --- | --- |
  | 미 장기국채 ~ 하이일드채 | 24.6% (주의) |
  | S&P500 ~ 나스닥 | 22.9% (주의) |
  | 하이일드채 ~ 원/달러 | 16.3% |
  | 미 장기국채 ~ 원/달러 | 11.6% |

  > 8주 표본만 보면 `tlt`~`hyg` 가 38%로 나와 만성처럼 보인다. 표본이 얇아
  > 생기는 착시이므로 **전 기간으로 재측정한 값이 판단 기준**이다.

  `tlt` 의 위험 성격(색)은 연속 스케일이라 별도 검증이 필요 없다 — 2022년 금리상승기처럼
  국채가 "방어"가 아니었던 국면은 색 농도로 자동 반영된다.

  라벨 충돌 회피(겹칠 때 오프셋)로 완화하되, 붙어 있다는 것 자체가
  "채권이 한 덩어리로 움직인다 / 미국 주식이 한 덩어리로 움직인다"는 정보이므로
  억지로 떼어놓지 않는다
- 사분면 요약 문장의 규칙 임계값은 구현 중 실데이터를 보며 조정한다
